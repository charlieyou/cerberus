## Codebase Patterns
- Plugin entry points live in `.amp/plugins/` and require the `// @i-know-the-amp-plugin-api-is-wip-and-very-experimental-right-now` header
- Use `import.meta.dir` to resolve plugin root; prompts live in `prompts/` relative to project root
- State directory: `.tmp/cerberus/<thread-id>/` for per-thread gate persistence
- Typecheck verification: `PLUGINS=all amp plugins list` confirms plugin loads; `PLUGINS=all amp plugins exec <plugin> <event> --data '{}'` tests execution
- Sanitize thread IDs with `id.replace(/[^a-zA-Z0-9._-]/g, '_')` for filesystem paths
- Export shared utilities (getPluginRoot, loadPrompt, resolveThreadStateDir) from cerberus.ts for use by future library modules
